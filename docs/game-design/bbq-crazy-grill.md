# 疯狂烧烤摊 - 产品方案

## 1. 产品概述

**游戏名称**：疯狂烧烤摊（BBQ Crazy Grill）
**核心玩法**：食材分类消除 - 将食材放入烤盘，同一烤盘凑齐3个相同食材即可消除
**目标平台**：纯 H5 网页（移动端优先）
**参考游戏**：疯狂烧烤摊（微信小游戏）

## 2. 核心玩法设计

### 2.1 游戏场景
- 屏幕上方显示关卡信息、倒计时
- 中间是**12个烤盘**，排成 3列 x 4行 的网格布局
- 每个烤盘旁边有**食材托盘**（左侧或右侧），是食材来源
- 底部是**道具栏**

### 2.2 核心循环
1. 每关生成一批食材，分布在各个食材托盘上
2. 玩家**点击食材托盘上的食材** → 食材飞入对应的烤盘
3. 每个烤盘**最多容纳3个食材**
4. 当烤盘上有**3个相同食材**时 → 自动消除，烤盘清空
5. 消除所有食材或达到目标数量 → 通关
6. 烤盘全满且无法消除 → 游戏失败

### 2.3 食材托盘机制
- 每个烤盘左右两侧各有一个食材托盘（或只有一侧）
- 食材托盘上的食材层叠排列，只能点击最上面的
- 食材托盘上的食材数量由关卡配置决定
- 点击食材 → 食材飞入相邻的烤盘

### 2.4 烤盘机制
- 12个烤盘，每个最多3个食材槽位
- 食材横排显示在烤盘上
- 3个相同食材 → 发光高亮 → 消除动画 → 清空烤盘
- 烤盘满（3个不同食材）→ 该烤盘锁定，无法再放入
- 玩家也可以点击烤盘上已有的食材，将其移到另一个有空位的烤盘（策略性操作）

### 2.5 关卡设计
- 每关有**倒计时**（如5分钟递减）
- 关卡进度：已消除数/总食材数
- 随关卡推进：
  - 食材种类增加（3种 → 8种+）
  - 总数量增加
  - 时间缩短
  - 层叠更深

## 6. 视觉风格
- 暖色调木质背景（类似烧烤摊桌面）
- 烤盘：深色带烤架纹理
- 食材托盘：浅色/白色小碟子
- 消除时发光 + 烟雾粒子效果
- 整体卡通风格

## 7. 技术要求
- 纯 HTML + CSS + JS，无框架依赖
- 修改现有 `public/bbq/` 目录下的文件
- 移动端优先，支持触摸操作
- 流畅的食材飞行和消除动画
- localStorage 存档
